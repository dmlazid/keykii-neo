# KeyKii Neo Brand Assets

This folder keeps the approved KeyKii Neo logo assets.

- **KeyKii-Neo-Official-Color.webp** — official pastel color logo.
- **KeyKii-Neo-Monochrome.webp** — monochrome/themed icon reference.

Use the color logo for normal branding, app-store graphics, splash screens, and marketing.
Use the monochrome version when a platform or phone theme needs a one-color icon.
