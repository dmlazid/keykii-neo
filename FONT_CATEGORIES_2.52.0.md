# KeyKii Neo 2.52.0 — Font Categories

The Fonts shop now uses a five-part visual browser inspired by the approved reference:

- New
- Categories
- Colorful
- Selected
- Trending

The five tabs use pastel icon tiles across the top of the Fonts screen.

## Behavior
- Categories keeps the complete 1,083-font library and the current FREE / PRO / AD grouping.
- New highlights the 28 new bundled fonts plus recent additions from the larger library.
- Colorful surfaces playful, bubble, brush, retro, expressive and decorative alphabet styles.
- Selected shows the font currently applied to the keyboard.
- Trending surfaces a curated popular collection plus additional library styles.
- Switching sections returns the Fonts page to the top instead of jumping to the previous scroll position.
- Fonts remain independent from themes, so users can combine a purchased/unlocked font with any chosen theme.

No keyboard height, bottom spacing, theme renderer, translator, cursor control, emoji or kaomoji behavior was changed.
