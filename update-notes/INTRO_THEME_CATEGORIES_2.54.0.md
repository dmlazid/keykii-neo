# KeyKii Neo 2.54.0 — Reliable Intro + Theme Categories

## Opening intro
- The shop intro is now versioned so it will appear once after installing/updating to 2.54.0, even for users who already opened an older KeyKii build.
- New intro follows the shop look: large KeyKii icon, KeyKii Keyboard title, Themes / Fonts / Color feature cards, app-language selector, and Get Started button.
- App language remains changeable later from Settings > Language.
- Finishing the intro records version 254 so it does not appear every time the app opens.

## Theme Shop categories
Adds a horizontal shop filter bar:
All | Free | Pro | Cute | Aesthetic | Dreamy | Dark | Nature | Seasonal

- Free and Pro use the existing real theme access classification.
- Cute, Aesthetic, Dreamy, Dark, Nature and Seasonal filter the existing 40 theme packs.
- All keeps the complete theme collection, My themes, and Fine tune controls.
- Filtered categories keep the screen cleaner by showing only matching theme packs.

## Preserved
- Existing theme artwork and previews.
- Existing font shop, 300 color fonts and 1,383 total font styles.
- Existing bottom shop navigation.
- Keyboard height, bottom spacing, translator, grammar, cursor control, emoji and kaomoji behavior.
