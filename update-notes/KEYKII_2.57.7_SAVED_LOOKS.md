# KeyKii Neo 2.57.7 — Saved Looks

## New
- Mine can now save a complete **theme + font** combination as a Saved Look.
- One tap on **Apply look** restores both the theme and the font together.
- Saved Looks are local-only and require no account.
- Up to 12 looks are kept so Mine stays fast.
- Removing a Saved Look does not delete the underlying theme/font favorite.

## Access behavior
- If a Saved Look contains a PRO/ad-gated theme or font and the 24-hour pass has expired, KeyKii asks for the rewarded-ad unlock before applying it.
- Free combinations apply immediately.

## Fix
- Mine's **Current theme** now shows the actual applied Theme Shop theme name when a style pack is active, instead of falling back to the base color-theme name.

## Preserved
Theme/font search, favorites, recents, 24-hour ad access, anti-repeat theme ordering, renderer behavior, translator, grammar, cursor control, emoji/kaomoji, languages and 2.54.4 performance fixes remain unchanged.
