# KeyKii Neo 2.57.6 — Theme & Font Search

## New
- Added a fast search box to Theme Shop.
- Search covers all 512 Neo themes plus the 40 original themes.
- Theme search checks theme names, descriptions, tags, scene names and architecture names.
- Added a search box to Font Shop covering the full font collection.
- Font search includes built-in, featured, color and remote fonts.
- Exact duplicate font names are suppressed in search results.
- Search initially renders only 24 results, with Show more, so it does not load hundreds of preview cards at once.

## Behavior
- Clearing the search returns to the current shop/category view.
- Choosing a category clears the active search.
- Search does not change the current applied theme/font until the user opens a preview and applies it.
- Existing 24-card theme batching, anti-repeat category ordering, favorites, recents, ad access, keyboard tools and 2.54.4 performance fixes remain unchanged.
