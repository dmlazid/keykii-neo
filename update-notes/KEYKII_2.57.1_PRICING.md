# KeyKii Neo 2.57.1 — Theme Shop pricing UI

This update adds visible launch pricing to the Theme Shop without changing the working renderer, category anti-repeat logic, fonts, language tools or keyboard behavior.

## Launch prices
- FREE themes: ₱0
- Regular PRO theme: ₱19
- Premium / more complex PRO theme: ₱29
- 5-theme pack: ₱79
- Category pack: ₱99
- Lifetime PRO launch price: ₱249

## UI changes
- Theme cards now show the actual PRO launch price instead of only "PRO PREVIEW".
- The preview sheet shows the one-time price before the user applies a test preview.
- A compact Launch pricing card is shown under the Theme Shop hero.
- FREE themes still show FREE.
- PRO previews remain usable in this test build so visual QA can continue.

## Billing status
This is the pricing-display update. Real checkout is intentionally not faked: Google Play Billing products still need to be created/configured before public release. The UI states that clearly.
