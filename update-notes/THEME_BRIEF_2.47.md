# KeyKii Neo 2.47.0 — 20 Asset Theme Rebuild

## Stable collection
The existing packs 100–119 stay intact. Purple Lotus Watercolor (116) is not redesigned.

## Replacement asset collection
Packs 120–139 are rebuilt from the user's keyboard-theme references as bundled wallpaper/sticker-style WebP assets generated at build time and committed by GitHub Actions.

### Design rules
- Full-board wallpaper composition, not a flat color plus 3–4 giant motifs.
- Many smaller coordinated details: checks, stripes, stars, clouds, flowers, bows, animals, café items, snow, waves and scrapbook details.
- Artwork sits behind the keys so letters stay readable.
- Theme Shop card, large preview and applied keyboard use the same asset.
- Keycap styles and corner radii vary across packs.
- Keys stay thin/light with the existing 55% More transparent default.
- Fonts remain separate from themes.
- No keyboard-height or bottom-spacing changes.
