# KeyKii Neo 2.57.4 — Favorites & Mine collection

## Why
With 512 new theme compositions plus the original themes, it became too easy to lose a design after browsing. This update makes the Mine tab useful as a personal collection instead of only showing the current theme/font.

## New
- Every Theme Shop preview now has **♡ Save / ♥ Saved**.
- Saved themes are stored locally on the device.
- Theme cards show a heart when the theme is already saved.
- Applying a theme automatically adds it to **Recently used**.
- Mine now includes:
  - 24-hour ad access status
  - current theme
  - current font
  - saved-theme count
  - favorite-theme preview grid
  - recently used theme preview grid
  - keyboard quick-test box
- Favorites and recents require no account and no internet.

## Limits / performance
- Mine renders at most 12 favorite cards and 8 recent cards at once.
- The main Theme Shop still uses the existing 24-card lazy-loading and anti-repeat ordering.
- No theme renderer, font renderer, keyboard height, language, translator, grammar, cursor, emoji/kaomoji or ad-access behavior was changed.
