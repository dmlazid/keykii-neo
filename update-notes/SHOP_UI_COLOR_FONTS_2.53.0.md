# KeyKii Neo 2.53.0 — Shop UI, Intro, App Language & Color Fonts

## Shop-style app
- Adds a persistent bottom navigation with Themes, Fonts, Mine and Settings.
- Themes is now the normal landing shop after onboarding.
- Mine includes a keyboard test box plus shortcuts to the user's current theme and font.
- Settings is redesigned into grouped purple-outline cards inspired by the approved reference.

## First-open intro
- Adds a first-run KeyKii intro screen.
- Users choose the app language before entering the shop.
- The intro appears once on normal app launch.
- App language can be changed later from Settings > Language.

## App language
Initial choices:
- English
- Filipino
- Cebuano
- Español

The selected app language is separate from keyboard input languages.

## Font Shop
- New compact filter bar:
  All | Selected | Free | Pro | Trending | Color Fonts
- Adds 300 actual color-font keyboard styles.
- Color styles combine 30 palettes with 10 real bundled typefaces.
- Color is applied to real keyboard letters, number labels and hints, not only preview cards.
- 60 color styles are FREE/AD and 240 are PRO.
- Total Font Shop styles: 1,383.
- Typed output remains normal text. Styling stays on the KeyKii keyboard.

## Preserved
- Existing themes and renderer.
- Existing 1,083 font styles.
- Keyboard height and bottom spacing.
- Translator, grammar, cursor control, emoji and kaomoji behavior.
