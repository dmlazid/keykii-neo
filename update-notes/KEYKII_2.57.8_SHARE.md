# KeyKii Neo 2.57.8 — Share with Friends

## New
- Added **Share KeyKii** under Settings > App.
- Added a Share KeyKii section in **Mine**.
- Android share sheet can send KeyKii through Messenger, Telegram, email, Nearby/Quick Share-compatible apps and other installed sharing apps.
- Added **Copy APK download link**.
- The shared URL is generated from the installed app version, so 2.57.8 automatically shares the 2.57.8 APK instead of an old build.
- Added an in-app installation guide for friends.
- Added the matching GitHub release-folder link.

## Safety / behavior
- Sharing sends a URL, not private app data.
- No contacts permission is requested.
- The friend still chooses where to send the link through Android's normal share sheet.
- Test builds continue using Google test ads; shared test installs do not produce ad revenue.

## Preserved
Saved Looks, theme/font search, favorites, recents, 24-hour access, theme renderer, original 40 themes, 512 Neo themes, keyboard tools and 2.54.4 performance fixes remain unchanged.
