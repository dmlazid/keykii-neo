## Full description
Make your keyboard feel like yours with KeyKii Neo.

KeyKii Neo combines expressive keyboard themes, hundreds of font styles, emoji and kaomoji, practical typing tools, translator features, clipboard tools, cursor control and more in one customizable Android keyboard.

### Themes
Browse hundreds of keyboard designs across cute, kawaii, dreamy, dark, gaming, floral, food, retro, Y2K, minimal, luxury, space, ocean, city and seasonal styles. Theme previews match the live keyboard renderer so you can see the design before applying it.

### Fonts
Choose from a large font collection and combine your favorite keyboard alphabet style with any theme.

### Smart keyboard tools
• Emoji and kaomoji
• Clipboard history and pinned clips
• Cursor control from the spacebar
• Translator tools
• Grammar Fix
• Text case tools
• Calculator
• One-handed and wide keyboard layouts
• Adjustable keyboard height and spacing
• Optional number row
• Voice typing support

### Free, rewarded and PRO access
KeyKii includes free themes and fonts. Eligible premium styles can also be used for 24 hours after completing a rewarded ad. One-time paid options are planned for the store.

### Privacy-focused typing
Normal typing is processed on your device. Network access is used only by features that need it, such as selected translation/grammar functions and advertising. Incognito mode can pause clipboard-history and emoji-recent saving.

KeyKii Neo is designed to make everyday typing more personal, useful and fun.
