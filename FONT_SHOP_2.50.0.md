# KeyKii Neo 2.50.0 — Fonts Shop

The Fonts screen is redesigned around the compact scrolling font-store layout
from the approved reference.

- 31 real selectable keyboard font styles
- compact rows so many fonts are visible at once
- each row renders the font name using that exact typeface
- FREE / PRO badges on the right
- selected font clearly marked
- tap opens the existing live keyboard preview before applying
- fonts remain completely separate from themes
- selected font is still used by the real KeyKii keyboard, not only the settings preview

No keyboard height, spacing, theme, translator, cursor-control, emoji or kaomoji behavior is changed.
